# RealWorldCerts Deployment & Operations

This guide covers how to build, deploy, and monitor the RealWorldCerts site.

## 1. Secrets Setup (GitHub Actions)

Go to **Settings > Secrets and variables > Actions** and ensure these secrets are set:

### Production (Required)
- `SITE_PUBLIC_URL`: `https://www.realworldcerts.com`
- `PAYPAL_OWNER_EMAIL`: `younesdgc@gmail.com` (or your preferred routing email)
- `DEPLOY_HOST`: IP or hostname of your production server.
- `DEPLOY_USER`: SSH user (e.g., `root` or `ubuntu`).
- `DEPLOY_SSH_KEY`: Private SSH key content (PEM format).
- `DEPLOY_PATH`: Target directory on server (e.g., `/opt/realworldcerts`).

### Staging (Optional)
- `STAGING_DEPLOY_HOST`
- `STAGING_DEPLOY_USER`
- `STAGING_DEPLOY_SSH_KEY`
- `STAGING_DEPLOY_PATH`

## 2. Deployment Workflows

### A. Build Container
**Workflow:** `Site Container Build`
- **Trigger:** Push to `main` or tag `v*`.
- **Action:** Builds Docker image and pushes to `ghcr.io/OWNER/realworldcerts-site:latest`.

### B. Deploy to Server
**Workflow:** `Site Deploy`
- **Trigger:** Manual Dispatch (Go to Actions tab -> Site Deploy -> Run workflow).
- **Inputs:** `environment` (default: `prod`).
- **Action:** 
  1. SSH into server.
  2. Copies `docker-compose.yml`.
  3. Pulls latest image.
  4. Restarts container (`docker compose up -d`).
  5. Verifies `/health`.

### C. Watchdog & Monitoring
**Workflow:** `Site Watchdog`
- **Trigger:** Schedule (Hourly) or Manual.
- **Action:** Runs `scripts/site-smoke-test.mjs` against `SITE_PUBLIC_URL`.
- **Checks:** 
  - `/health` (200 OK)
  - `/api/paypal-link` (Valid response)
  - `/feed.xml` (Valid RSS)
  - `/sitemap.xml`, `/robots.txt`
  - Content on core pages.
- **Notification:** Logs failure and intended alert to `younesdgc@gmail.com`.

## 3. Local Development & Verification

### Run Locally
```bash
npm run site:start
# Server runs on http://localhost:8080
```

### Generate Feed
```bash
npm run site:feed:gen
```

### Local Smoke Test
```bash
# In a separate terminal while server is running:
npm run site:smoke
```

### Docker Test
```bash
docker build -t site-local -f Dockerfile.site .
docker run -p 8080:8080 site-local
# Check http://localhost:8080/health
```

## 4. Troubleshooting

- **502 Bad Gateway:** Check Nginx logs on server. Ensure container is running on port 8080.
- **404 on Assets:** Ensure `npm run site:feed:gen` ran during build (it is in Dockerfile).
- **PayPal Link Error:** Check `PAYPAL_OWNER_EMAIL` env var in container or secrets.
